  • Merge Studioopens in a new tab

    4

    sd-webui-merge-studio

    Merge checkpoints and bake LoRAs on dequantized weights, with inspection and repair tools.

    Forge & Stable DiffusionForge Neo · Checkpoint tools
    More about this project

    A quantization-aware checkpoint merger for Forge Neo. Merges, converts, and bakes LoRAs on the dequantized weights instead of interpolating raw tensors like the native Checkpoint Merger — so it stays correct on fp8, int8, nvfp4 and Anima checkpoints, not just fp16/bf16. Ships a component inspector and a doctor tool that repairs a metadata bug common in community int8 models.
